# WinDev

## Portable Windows Scientific Development Environment

Welcome to the WinDev documentation.

WinDev is a portable, modular and reproducible Windows development environment designed for scientific and engineering software development.

This documentation is organized as a **book**: it starts with the motivation and design philosophy, then explains the architecture and entry point, followed by toolchains, environment management, build systems, libraries, testing, troubleshooting, maintenance, and reference material.

## Start Here

If you are new to WinDev, begin with **Part I — Motivation & Philosophy** and then continue through the architecture chapters.

The documentation is intentionally designed to preserve not only the final configuration, but also the reasoning, build procedures, failures, workarounds, and lessons learned while constructing the environment.
